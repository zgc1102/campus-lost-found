# 新人上手：从打开网站到改第一行代码

> 给完全没做过项目的队友。照着做，30 分钟能跑起来。
> 遇到卡住的地方，把报错截图发群里。

---

## 第 0 步：先打开网站看看

1. 双击电脑上的 **Edge** 或 **Chrome**
2. 在最上面的地址栏输入：

```
https://shiguangli.work
```

3. 按回车

你应该看到：

- 紫色顶部「清华校园拾光里」
- 一个 AI 扫描卡片
- 失物招领 / 寻物启事
- 爱心求助 4 个入口

如果弹出「欢迎来到清华校园拾光里」的引导，点「跳过」或点暗色空白处。

### 手机打开

用手机相机或微信扫二维码，或直接在浏览器输入同一个网址。

## 第 1 步：自己发一条试试

1. 点右下角圆形 **＋**
2. 选「我要寻物」或「我要招领」
3. 填：
   - 物品名称：`测试雨伞`
   - 分类：其他
   - 地点：`图书馆`
   - 描述：`一把蓝色雨伞落在图书馆一楼，求好心人看到`
   - 电话：`13800138000`
4. 点「提交发布」

等 3–10 秒，会显示发布成功或审核中。

### 看后台

1. 浏览器打开：

```
https://shiguangli.work/admin
```

2. 密码：**问组长要，不要发群里**
3. 登录后能看到刚才那条，可以「通过」「驳回」

---

## 第 2 步：装三个软件

### ① VS Code（写代码用）

1. 打开 `code.visualstudio.com`
2. 点蓝色 Download
3. 一路下一步安装

### ② GitHub Desktop（传代码用）

1. 打开 `desktop.github.com`
2. 下载安装
3. 打开后用 GitHub 账号登录

### ③ Python（本地运行用）

1. 打开 `python.org/downloads`
2. 下载 3.11 或 3.12
3. **安装时一定勾选 `Add Python to PATH`**
4. 装完打开「命令提示符」，输入：

```
python --version
```

看到 `Python 3.x.x` 就成功。

---

## 第 3 步：把代码下载到电脑

1. 打开 GitHub Desktop
2. 点 **File → Clone repository**
3. 选 **URL**，填：

```
https://github.com/zgc1102/campus-lost-found.git
```

4. 本地路径选一个好找的，比如 `D:\拾光里`
5. 点 **Clone**

> 前提：组长已经把你加成 Collaborator，并且你接受了邮件邀请。

---

## 第 4 步：用 VS Code 打开

1. 打开 VS Code
2. **File → Open Folder**
3. 选刚才的 `D:\拾光里`
4. 左边会出现文件列表

你会看到：

```
用户端.html       ← 用户看到的页面
管理端.html       ← 后台页面
assets/
  app.js          ← 用户端逻辑
  styles.css      ← 样式
  admin.js        ← 后台逻辑
server.py         ← 服务器
data/             ← 知识库
docs/             ← 文档
```

---

## 第 5 步：在自己电脑上跑起来

1. 在 VS Code 里点 **Terminal → New Terminal**
2. 输入：

```
python server.py
```

3. 看到 `Serving on` 或 `8000` 就成功
4. 浏览器打开：

```
http://127.0.0.1:8000
```

这就是你电脑上的版本，改代码后刷新就能看到。

> 关掉：在终端按 `Ctrl + C`

---

## 第 6 步：改第一行字

1. 在 VS Code 左边点开 `用户端.html`
2. 按 `Ctrl + F` 搜索：

```
清华校园拾光里
```

3. 把其中一处改成：

```
清华校园拾光里（测试）
```

4. 保存：`Ctrl + S`
5. 浏览器刷新 `http://127.0.0.1:8000`

标题变了，说明你改成功了。

---

## 第 7 步：把改动传上去

1. 打开 GitHub Desktop
2. 左下角会显示改了哪些文件
3. 在左下角输入说明：

```
测试：修改标题
```

4. 点 **Commit to main**
5. 点右上角 **Push origin**

---

## 第 8 步：让线上生效

1. 打开 `https://shiguangli.work/admin`
2. 点顶部「**更新代码**」
3. 等 12 秒，页面自动刷新
4. 打开网站，看到你改的字

> 如果提示更新失败，把弹出的日志发群里。

---

## 第 9 步：每天开工前的习惯

```
1. 打开 GitHub Desktop
2. 点 Fetch origin
3. 有更新就点 Pull origin
4. 再开始改
```

**不 Pull 就改，Push 会冲突。**

---

## 第 10 步：常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `python` 不是命令 | 没勾 Add to PATH | 重装 Python，勾选 PATH |
| 打开 127.0.0.1:8000 是空白 | 服务没启动 | 终端重新 `python server.py` |
| 页面是旧版 | 浏览器缓存 | `Ctrl + F5` |
| Push 失败 | 没先 Pull | 先 Pull，再 Commit |
| 后台登录不上 | 密码错 | 问组长，不要猜 |
| 改了没生效 | 没点更新代码 | 后台点「更新代码」 |

---

## 不要做的事

- ❌ 不要改服务器上的文件
- ❌ 不要提交 `items.json`、`.env`、`admin.json`
- ❌ 不要把自己的密码、Key 写进代码
- ❌ 不要直接改 `server.py`（先问组长）
