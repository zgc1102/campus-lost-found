## 二、三个人怎么协作

### 1. 给队友开权限（组长做一次）

1. 打开仓库 → **Settings** → **Collaborators**
2. **Add people** → 输入队友 GitHub 用户名
3. 队友接受邮件邀请

### 2. 队友第一次拿代码

装 **GitHub Desktop**（图形界面，不用记命令）：

1. 下载 `desktop.github.com`
2. 登录自己的 GitHub 账号
3. **File → Clone repository** → 选 `zgc1102/campus-lost-found`
4. 选本地文件夹 → Clone

再用 **VS Code** 打开这个文件夹。

### 3. 每次改代码的流程

```
先 Pull（拉最新） → 改 → Commit（写一句说明） → Push（推上去）
```

GitHub Desktop 里：

1. 右上角 **Fetch origin** → 有更新就 **Pull origin**
2. 改文件
3. 左下角填说明，例如「修复图片放大」
4. **Commit to main**
5. 右上角 **Push origin**

### 4. 冲突怎么办

两个人改了同一个文件同一行，Push 会失败：

1. 先 **Pull origin**
2. GitHub Desktop 会标红冲突文件
3. 打开文件，找 `<<<<<<<` `=======` `>>>>>>>`，保留要的代码，删掉标记
4. 重新 Commit + Push

**规矩：改之前先 Pull，一天至少 Pull 两次。**

## 三、代码改哪里

```
拾光里共享版/
├─ 用户端.html          # 用户看到的页面结构（文字、按钮、弹层）
├─ 管理端.html          # 后台页面结构
├─ assets/
│  ├─ styles.css        # 用户端样式（颜色、大小、间距）
│  ├─ app.js            # 用户端逻辑（发布、认领、AI、地图、证书）
│  ├─ admin.css         # 后台样式
│  └─ admin.js          # 后台逻辑
├─ server.py            # 后端：接口、AI 审核、匹配、账号
├─ data/kb/*.md         # 问答知识库（改这里，AI 回答会变）
├─ docs/                # 文档
└─ scripts/             # 部署、压测脚本
```

### 常见修改对照表

| 想改什么 | 改哪个文件 | 怎么改 |
|---|---|---|
| 首页标题、按钮文字 | `用户端.html` | 直接搜文字，改掉 |
| 颜色、圆角、字号 | `assets/styles.css` | 改对应的 class |
| 发布校验、认领流程 | `assets/app.js` | 搜函数名，如 `claimCard` |
| 审核规则、提示词 | `server.py` | 搜 `AI_PROMPT`、`ai_llm` |
| 问答知识 | `data/kb/*.md` | 直接加一段 |
| 加一个接口 | `server.py` | 在 `do_POST` 里加 `if path == "/api/xxx":` |
| 管理端加按钮 | `管理端.html` + `assets/admin.js` | HTML 加按钮，JS 绑事件 |

### 改完记得做两件事

1. **本地跑一遍**

```bash
python server.py
```

打开 `http://127.0.0.1:8000`，本地管理员密码在 `管理员密码.txt`。

2. **改了 css/js 就升版本号**

`用户端.html` 里：

```html
<link rel="stylesheet" href="assets/styles.css?v=20261104">
<script src="assets/app.js?v=20261104"></script>
```

把 `20261104` 改成当天日期，否则用户浏览器会用旧缓存。

## 四、怎么发布到线上

### 方法 A：后台一键更新（推荐）

1. 代码 Push 到 GitHub
2. 打开 `https://shiguangli.work/admin`
3. 顶部点「**更新代码**」
4. 等 10 秒，刷新页面

### 方法 B：阿里云命令助手（一键按钮坏了时）

阿里云控制台 → 轻量服务器 → 命令助手 → 执行：

```bash
cd /opt/lostfound && git pull --ff-only && systemctl restart lostfound
```

### 方法 C：SSH（能连上服务器时）

```bash
ssh root@服务器IP
cd /opt/lostfound && git pull && systemctl restart lostfound
```

> 只改 HTML/CSS/JS：`git pull` 就生效。
> 改了 `server.py`：必须 `systemctl restart lostfound`。

## 五、数据和备份

数据都在服务器 `/opt/lostfound/`：

| 文件 | 内容 |
|---|---|
| `items.json` | 所有发布 |
| `claims.json` | 认领申请 |
| `notices.json` | 通知 |
| `accounts.json` | 注册账号 |
| `announcements.json` | 公告 |
| `ai.json` | AI 开关和参数 |
| `admin.json` | 管理员密码 |

**这些文件不在 Git 里**，`git pull` 不会覆盖，放心。

### 备份

```bash
cd /opt/lostfound
tar czf /root/backup-$(date +%F).tar.gz items.json claims.json notices.json accounts.json announcements.json
```

### 恢复

```bash
tar xzf /root/backup-2026-11-01.tar.gz -C /opt/lostfound
systemctl restart lostfound
```

## 六、AI Key 怎么退出（重点）

项目现在用两个外部 AI：

| 用途 | 平台 | 配置位置 |
|---|---|---|
| 文本审核、核验、问答 | DeepSeek | `.env` 的 `DEEPSEEK_API_KEY` |
| 图片识别、图片审核 | 智谱 GLM | `.env` 的 `VISION_API_KEY` |

这两把 Key 是**私人账号**，交接时必须换掉，否则一直扣你的钱。

### 第 1 步：先停用（立刻止血）

后台 `/admin` → 顶部 AI 设置 → 「修改」→ 关闭「启用」。

或者命令：

```bash
cd /opt/lostfound
python3 -c "import json;d=json.load(open('ai.json'));d['enabled']=False;json.dump(d,open('ai.json','w'),ensure_ascii=False)"
systemctl restart lostfound
```

关掉后：审核退回**规则模式**，可疑内容不会自动放行，会留在待审核，不会乱发。

### 第 2 步：换 Key（学校提供新账号时）

编辑 `/opt/lostfound/.env`：

```bash
nano /opt/lostfound/.env
```

改成学校给的 Key：

```
DEEPSEEK_API_KEY=sk-学校的新key
DEEPSEEK_MODEL=deepseek-chat
VISION_API_KEY=学校的智谱key
VISION_MODEL=glm-4v-flash
```

保存后：

```bash
systemctl restart lostfound
```

### 第 3 步：删除旧 Key（关键）

只改服务器不够，**要去平台把旧 Key 删掉**：

- DeepSeek：`platform.deepseek.com` → API Keys → 删除
- 智谱：`open.bigmodel.cn` → API Keys → 删除

删掉后即使别人拿到旧 Key 也用不了。

### 第 4 步：停掉自动扣费

- DeepSeek：账户 → 充值/支付 → 解绑支付方式，不再充值
- 智谱：同样解绑

### 第 5 步：确认没在扣钱

等一天，看两个平台的账单/用量是否为 0。

### 交接清单

- [ ] AI 开关已关闭或换成学校 Key
- [ ] 旧 Key 已在平台删除
- [ ] 支付方式已解绑
- [ ] 管理员密码已改
- [ ] 服务器 root 密码已改
- [ ] 域名和 Cloudflare 账号已移交
- [ ] 数据已备份一份给学校

## 八、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 打开 502 | 后端刚重启 | 等 10 秒刷新 |
| 页面是旧版 | 浏览器缓存 | Ctrl + F5；确认版本号改了 |
| 后台登录不上 | 密码不对 | `cat /opt/lostfound/admin.json` |
| AI 不工作 | Key 失效/没开 | 后台 AI 设置里点「测试」 |
| 更新代码失败 | 服务器有本地改动 | 命令助手执行 `cd /opt/lostfound && git status` 看冲突 |
| 图片不显示 | 图片太大被压缩 | 正常，列表只存压缩图 |
