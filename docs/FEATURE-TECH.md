|---|---|---|---|
| 发布寻物/招领 | 发布页 | Vue 组件 + AI 自动审核 + 规则兜底 | 发布后自动上架/驳回 |
| AI 看图 | 发布上传 | 多模态视觉模型 | 管理端 AI 看图总结 |
| 拾光码 | 我的 / 拾光码 | 二维码、持久化、扫码通知、注销 | 扫码 → 通知 → 认领 |

| AI 寻物雷达 | 首页雷达 | Agent 工具调用、文本匹配、热点统计 | Agent Trace 三步工具 |
| 寻物侦探 | 雷达下方 | 路线推理、校园地点 RAG | 行动顺序与推理步骤 |
| 校园问答 | 指路页 | BM25 校园知识检索 + LLM | 回答带来源 |
| 认领核验 | 物品详情 | 核验 Agent、证据链、取件码 | 认领通过 → 取件码 → 闭环 |
| AI 审核管理 | /admin | 评分、建议、理由、重新审核 | 管理端 AI 审核块 |
| 公告/用户/白名单 | /admin | 管理端 CRUD + 权限 | 操作留痕 |
| 通知中心 | 通知页 | 站内通知 + 深链 itemId | 扫码通知可操作 |
| 图片查看 | 失物/求助/管理 | 全屏图片查看器 | 点图片放大 |
| 部署更新 | /admin | Git + systemd + 数据备份 | 更新代码、部署日志 |

## AI 技术点与位置

- **大模型**：DeepSeek，审核、问答、侦探、雷达总结
- **多模态**：图片理解，生成 visionDesc
- **Agent**：雷达三步工具、侦探路线推理、认领核验
- **RAG**：本地 BM25 校园知识 + 来源
- **规则引擎**：AI 失败兜底、手机号校验、范围拦截
- **自动审核**：全自动，不设人工审核队列
- **SSE**：核验过程流式接口 `/api/agent/review/stream`

## 比赛演示顺序

1. 首页讲痛点
2. 拾光码生成 → 另一台手机扫码 → 失主通知
3. 发布寻物 → AI 审核 → 雷达 Agent Trace
4. 侦探路线推理
5. 认领 → 取件码 → 已闭环
6. 管理端 AI 评分与治理
7. 评测数据与架构总结
